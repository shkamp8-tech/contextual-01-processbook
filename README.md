# Procesboek – Contextual 01

Digitaal procesboek / canvas om je werkproces en onderzoek overzichtelijk bij te houden.

## Features

- **Canvas-weergave** met kaarten per onderzoek of processtap
- **Licht & donker thema** (schakelen via 🌙/☀️ knop)
- **Fases**: Onderzoek, Concepting, Ontwerp, Prototype, Testen, Reflectie
- **Links** naar onderzoeken (openen in nieuw tabblad)
- **Lokale opslag** – kaarten worden bewaard in de browser (localStorage)

## Gebruik

Open `index.html` in een browser. Klik op **+ Kaart** om je werk toe te voegen.
